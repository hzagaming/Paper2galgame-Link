# v2.1.0：声音与体验稳定性更新

发布日期：2026-08-16

v2.1.0 对新版入口页进行了发布级复查：

- 新增默认关闭、由用户主动开启的程序化环境 BGM，不引入外部音频资源。
- 将 SFX 与 BGM 拆分为独立控制，并统一开关状态与无障碍语义。
- 补齐 Web Audio 的恢复、暂停、页面隐藏、BFCache 与离页资源清理流程。
- 修复触摸与点击可能重复触发音效的问题，并支持键盘反馈。
- 为指针动画加入逐帧节流，为入场动画加入幂等处理。
- 修复“减少动态效果”开启时后台标签页可能保持空白的问题。
- 将移动端声音按钮扩大到至少 44 × 44 px，并新增矮屏横向双栏布局。

后续更新见 [当前公告](../../../ANNOUNCEMENT.md)，更早版本见 [v2.0.0](v2.0.0.md)。
